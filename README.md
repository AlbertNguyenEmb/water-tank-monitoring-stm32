# Water Tank Level Monitoring and Automatic Pump Control

---

## Overview

STM32-based water tank monitoring system using analog water level sensing.

Features

- Water Level Monitoring
- Automatic Pump Control
- LCD Display
- UART Logging
- Error Detection
- FSM Control
